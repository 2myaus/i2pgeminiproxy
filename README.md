# i2pgeminiproxy

this is a really simple proxy that allows a gemini client to browse gemini sites on i2p. it works by basically just forwarding your gemini request to the remote server, with very little going on beyond that. it uses goSam to talk to your i2p router.

this project is a work-in-progress. i want to make the proxy more configurable, handle errors better, and verify that it is actually secure and private (which it may not be). this is also my first project written in go.

however, it does currently seem to mostly work.

i will do my best to respond to anyone who wishes to contribute to this, which i would also greatly appreciate.
